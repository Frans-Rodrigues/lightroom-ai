# Lightroom AI Assistant

Sistema inteligente para análise de imagens e geração de sugestões de edição no Adobe Lightroom Classic em português.

---

# Objetivo

O projeto foi criado para ajudar fotógrafos e editores a:

- analisar imagens automaticamente
- receber sugestões completas de edição
- acelerar o workflow no Lightroom
- entender quais ajustes devem ser feitos
- aprender color grading profissional

---

# Funcionalidades atuais

✅ Upload de imagem  
✅ Colar print com CTRL + V  
✅ Interface web responsiva  
✅ Painéis organizados igual ao Lightroom  
✅ Sugestões de edição em português  
✅ Estrutura pronta para IA futura
